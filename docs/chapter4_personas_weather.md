# 第四章：四大微觀人群像與天候彈性——誰在移動？風雨如何改寫動線？

> 「在粗暴的總量曲線背後，每一個刷卡聲都有名字：可能是清晨趕著打卡的工程師，或是牽著孫子搭捷運避暑的阿嬤。風雨一來，他們的命運完全不同。」

---

## 4.1 告別無臉大數據：從粗總量走向微觀人群像

長期以來，傳統都市規劃常使用「一人一票」的無差別統計。然而，當政策制定者只看總運量時，往往會忽略弱勢族群的真實痛點：
* **如果只看尖峰人潮，我們就會以為非尖峰時段的捷運不需要服務——但那是長者前往醫院看診的唯一生命線。**
* **如果以為所有人都會因為下雨改搭計程車——卻忽略了買了 TPASS 的學生依然必須在雨中轉乘公車。**

透過解構交通部 TICP 票證資料中的法定身分代碼（TicketType），本系統精準還原了全台**四大微觀人群像（Micro-Personas）**，並進一步打造了全台首創的**天候模擬實驗室（Weather Simulation Lab）**。

---

## 4.2 四大微觀人群像深度畫像

```
┌─────────────────────────┬─────────────────────────┐
│  👔 鋼鐵通勤族           │  👵 悠遊銀髮族          │
│  (Iron Commuters)       │  (Active Seniors)       │
│  • 票種：TPASS 月票     │  • 票種：敬老愛心卡     │
│  • 特徵：早晚尖峰雙峰   │  • 特徵：離峰買菜、看診 │
├─────────────────────────┼─────────────────────────┤
│  🎓 求學青年族           │  🏖️ 假日觀光客          │
│  (Gen-Z Students)       │  (Weekend Tourists)     │
│  • 票種：學生卡 (02)    │  • 票種：單程票 Token   │
│  • 特徵：補習商圈群聚   │  • 特徵：風景區、週末潮 │
└─────────────────────────┴─────────────────────────┘
```

### 1. 👔 鋼鐵通勤族 (Iron Commuters)
* **核心標籤**：`TicketType=4` (TPASS 月票持有者)、跨縣市通勤、高頻剛需。
* **時序節奏**：極端對稱的「雙峰曲線」（07:30~09:00 早尖峰，17:30~19:30 晚尖峰）。
* **行為特徵**：對行程時間可靠度極度敏感，換乘時間容忍度低（偏好高鐵轉捷運、直達客運）。TPASS 政策大幅降低其邊際出行成本，使跨市移動（如基隆 ➔ 台北、桃園 ➔ 雙北）常態化。

### 2. 👵 悠遊銀髮族 (Active Seniors)
* **核心標籤**：`TicketType=03/04` (65 歲以上敬老卡、愛心卡)。
* **時序節奏**：完全避開早晚尖峰！高峰落在 **09:30~11:30**（晨間公園運動、傳統市場採買）與 **14:00~16:00**（醫院回診、松年大學課程）。
* **行為特徵**：依賴無障礙設施、低地板公車與電梯。對天候極度敏感（雨天摔倒風險抑制出行）。

### 3. 🎓 求學青年族 (Gen-Z Students)
* **核心標籤**：`TicketType=02` (高中職與大專院校學生票)。
* **時序節奏**：清晨 07:00 提早抵校，傍晚 16:30~17:30 放學；晚間 20:30~21:30 出現顯著的「補習班散場潮」。
* **行為特徵**：高頻群聚於補習街（如台北南陽街、台中一中商圈、高雄火車站前站）與夜市文創市集。

### 4. 🏖️ 假日觀光休閒客 (Weekend Tourists & Inbound Visitors)
* **核心標籤**：`Single Token` (單程代幣)、`QR Code 乘車碼`、短天期旅遊 Pass。
* **時序節奏**：平日運量低平，**週六日上午 10:00 爆發**，持續沸騰至深夜 22:30。
* **行為特徵**：高度集中於機場捷運、九份瑞芳客運、淡水渡船頭、西門町、高雄駁二等風景名勝，外籍旅客比例顯著。

## 4.3 風雨中的行為巨變：天候模擬實驗室

天候是交通行為最強大的「外部擾動因數（External Disruptor）」。
當氣象署發布「豪大雨特報」時，城市交通絕非等比例衰退，而是發生了劇烈的**運具間移轉（Modal Shift）**。

### 1. 四大天候階段模擬
本系統支援 4 階段氣候劇本模擬：
* **☀️ 晴天 (Sunny / Clear)**：基準運量，各運具按照常態時間表運轉。
* **⛅ 多雲 (Cloudy)**：微幅心理影響，部分戶外觀光行程向室內百貨商場微移。
* **🌧️ 雨天 (Rainy)**：地面路網降速 15%，YouBike 租借量驟降 45%。
* **⛈️ 豪大雨 (Heavy Rain / Storm)**：極端天氣壓力測試，路面嚴重積水與視線受阻。

### 2. 豪大雨下的運具彈性係數（Modal Elasticity）
透過實證數據對比，在豪大雨情境下各運具呈現截然不同的命運：

```
🚲 YouBike 公共自行車 ───▼ -78.4%  (幾乎全面停擺，轉移至步行或公車)
🚌 市區公車 (Bus)    ───▼ -22.6%  (路面壅塞、候車淋雨導致搭乘意願下降)
🚗 國道自駕車流      ───▼ -14.2%  (視線不佳抑制非必要非尖峰出行)
🚆 都會捷運 (Metro)  ───▲ +8.3%   (避雨首選！地下化站體完全不受風雨影響，承接大量轉移人潮)
🚅 高鐵 (THSR)       ───  -1.2%   (長途剛需穩定，幾乎不受市區風雨動搖)
```

### 3. 銀髮族的「極端天候外出脆弱性」
最震撼的數據發現發生在長者身上：
當天候由「晴天」轉為「豪大雨」時，**65+ 銀髮族外出刷卡人次瞬間暴跌 62.8%**！
這直接證明了：極端天候對銀髮族的生活圈構成了嚴重的「空間隔離」。社區醫療接駁專車與風雨走廊的建置，在超高齡社會中具有生死攸關的緊迫性。

## 4.4 🛠️ 互動操作實戰指引：如何在系統中體驗

### 操作步驟：
1. 點擊上方超連結或點擊頂部導覽列 **【微觀人群像】**。
2. **切換四大微觀人群像子頁籤**：
   * 點選 **「👔 鋼鐵通勤族」**：觀察早晚尖峰高聳入雲的雙峰時序圖與高鐵/捷運樞紐分佈。
   * 點選 **「👵 悠遊銀髮族」**：觀察平緩的午間晨間曲線，以及台北榮總、台大醫院周邊捷運站的長者刷卡聚落。
   * 點選 **「🎓 求學青年族」**：觀察補習街與學校周邊站點的晚間散場尖峰。
3. **啟動「天候實驗室 (Weather Simulation)」**：
   * 在畫面頂部找到天候下拉選單，依序切換 **「晴天 (Clear)」➔「雨天 (Rain)」➔「豪大雨 (Heavy Rain)」**。
   * 觀察畫面上即時計算的 **「運具脆弱性移轉百分比長條圖」**，親眼見證捷運如何逆勢抗跌、YouBike 如何劇烈下滑！
